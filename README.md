# Edexcel P3 真题训练

适合电脑、iPad 和手机浏览器使用的静态 PWA。程序本身不包含试卷或答案；用户从设备文件管理器导入自己的 PDF，文件保存在当前设备的浏览器存储中。

## 使用

1. 用电脑 Chrome / Safari、iPad Safari 或手机浏览器打开 GitHub Pages 地址。
2. 在 iPad 或手机上可以选择“添加到主屏幕”，以后像 App 一样打开。
3. 在每台需要使用的设备上分别导入题目与答案 ZIP；PDF 不会通过 GitHub 同步。

## PDF 阅读器

- 使用随网站一起缓存的 PDF.js，把指定页直接绘制到网页画布，不依赖各浏览器不同的内嵌 PDF 行为。
- 支持上一页、下一页、手动页码、适宽、放大和缩小；电脑键盘也可用左右方向键翻页。
- 如果文件本身不完整，阅读区会提示重新导出，并保留“打开原 PDF”的检查入口。
- 网站程序可离线打开；首次在某台设备上导入的题库也只属于该设备。

## 自动整理

- 支持分别导入题目 ZIP 与答案 ZIP，并按文件名自动归入 8 个章节。
- 大 ZIP 按单个 PDF 逐份读取，降低 iPad 的内存压力。
- 抽题时优先使用预先识别的真实题号 1—10，并按顺序定位答案页。
- 无法可靠识别的文件自动使用页段估算，同时保留手动翻页。
- 导入时检查 PDF 结尾；疑似损坏的文件会在题库管理中提示重新导出。

## 隐私

题库 PDF 不会上传到 GitHub。GitHub 仓库只保存本项目的 HTML、CSS、JavaScript 和图标。
